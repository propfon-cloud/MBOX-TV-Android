MBOX TV – Android TV Box v1.1.0
===============================

ЦЕЛ
---
Едно приложение за Android TV Box, което след първоначална настройка:
1) стартира автоматично;
2) показва MBOX TV или избрано лого, докато локалната мрежа/TV сървърът стане достъпен;
3) отваря зададения локален Web TV адрес на цял екран;
4) не изисква повторно въвеждане на адреса.

ПЪРВО ПУСКАНЕ
--------------
Въведи LAN адреса на компютъра/сървъра, например:
http://192.168.1.117/tv/

НЕ използвай http://localhost/... на Android TV Box. Там localhost означава самия TV Box.

ЛОГО
----
"Избери лого" позволява да избереш PNG/JPG/WebP от паметта или USB.
Картинката се копира във вътрешната памет на приложението и остава налична след изваждане на USB.
"Стандартно лого" връща надписа MBOX TV.

ИНТЕЛИГЕНТНО СТАРТИРАНЕ
------------------------
Няма фиксирано забавяне. Приложението проверява локалната мрежа и TV URL приблизително през 1.5 секунди.
Когато адресът отговори, Web TV се зарежда веднага на цял екран.
Докато няма връзка, се вижда логото и текст "Свързване…" / "Изчакване на мрежата…".

АВТОМАТИЧЕН СТАРТ
------------------
Има два механизма:
A) Start on boot – включен по подразбиране.
B) Direct flavor / Home Launcher – препоръчителен за постоянен TV Box. От настройките натисни
   "НАПРАВИ MBOX TV НАЧАЛЕН ЕКРАН" и избери MBOX TV като Home/Launcher и "Always".

СКРИТИ НАСТРОЙКИ
-----------------
Задръж BACK за 3 секунди.
PIN по подразбиране: 1234
PIN може да се промени.
Кратко натискане на BACK не затваря приложението.

BUILD
-----
GitHub Actions:
Проектът съдържа .github/workflows/build-apk.yml.
При push към main/master или ръчно Workflow Dispatch се компилира directDebug и се качва artifact:
MBOX_TV_APK -> MBOX_TV.apk

Android Studio:
1) Open -> папката на проекта
2) Gradle Sync
3) Build Variant: directDebug
4) Build -> Build APK(s)

=== V1.1.0 / ANDROID TV WEBVIEW MODE ===
- Препоръчителен адрес: http://IP-НА-СЪРВЪРА/tv/
- WebView пази PHP cookies/session при redirect към /tv/player.
- HTML5 video autoplay е разрешен без user gesture.
- Старият #start Play бутон се скрива автоматично.
- Видео елементът се показва и стартира автоматично след redirect.
- MutationObserver + периодичен retry поддържат player-а при бавно зареждане/DOM update.
- OK/ENTER от дистанционното е резервен ръчен trigger.
- При main-frame HTTP/network error се връща логото и приложението опитва отново.

=== V3 / 1.2.0 ===
- Нов iframe режим (включен по подразбиране) с TV URL от локалната мрежа.
- BACK задържан 3 секунди -> PIN -> Настройки / Рестарт / Изход към Android.
- Изходът унищожава WebView и прекратява процеса, с защита от незабавно връщане ако MBOX TV е Home/Launcher.
- В настройките може да се изключи iframe режимът и да се използва директен WebView.
